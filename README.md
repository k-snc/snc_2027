# 動物病院 2027年時流予測セミナー LP

GitHub Pages で公開するためのファイル一式です。

- `index.html` : LP本体(ルートに置く)
- `images/` : 講師写真(kitano.png / kanbara.png / aida.png / fukunaga.png)
- `.nojekyll` : GitHub Pages の自動処理を無効にするための空ファイル

## 公開手順(概要)
1. このフォルダの中身(index.html、images、.nojekyll、README.md)を、リポジトリのルートに置く
2. GitHub の Settings > Pages で、公開元を「Deploy from a branch」、ブランチ `main`、フォルダ `/ (root)` に設定
3. 公開URL: https://アカウント名.github.io/リポジトリ名/
